# سامانه کیوسک وندینگ داروخانه و بهداشت هوشمند (۲۱.۵ اینچ عمودی ۱۰۸۰×۱۹۲۰)

نسخه جدید و بازطراحی‌شده رابط کاربری کیوسک بر اساس طرح‌های ارسالی با سبک **Royal Violet & Raspberry Pharmacy Theme**، ویژه نمایشگر لمسی عمودی **۲۱.۵ اینچ Full HD (رزولوشن ۱۰۸۰ در ۱۹۲۰ با نسبت ۹:۱۶)** و سخت‌افزار مینی‌پی‌سی لینوکسی (پردازنده Core i5-5200U و گرافیک Intel HD 5500) با نرخ ۶۰ فریم بر ثانیه پایدار و مصرف منابع نزدیک به صفر.

---

## ۱. ساختار نماها و سناریوهای کاربری (مطابق تصاویر ارسالی)

1. **صفحه شروع / استندبای کیوسک (`view-idle` - عکس ۱۷):**
   - نشانگر فعال بودن دستگاه (`🟢 دستگاه آماده است`)
   - تیتر بزرگ: «برای شروع، صفحه را لمس کنید» با زیرعنوان «خرید سریع و خصوصی»
   - پیش‌نمایش ۴ دسته اصلی (محافظت، پریود، روان‌کننده، کیت‌های آماده)
   - دکمه‌های «شروع خرید >» و «تحویل سفارش اپ 📱»
   - برچسب امنیتی «🛡️ بدون دوربین • بدون ثبت اطلاعات شخصی»
   - بازگشت خودکار به این صفحه در صورت عدم لمس صفحه پس از ۴۵ ثانیه

2. **صفحه انتخاب دسته‌بندی اصلی (`view-categories` - عکس ۱۶ و ۲۸):**
   - عنوان: «چه چیزی نیاز دارید؟»
   - ۴ کارت بزرگ با پس‌زمینه رنگی و آیکون‌های اختصاصی در چیدمان ۲×۲
   - دکمه عریض «✨ راهنمای انتخاب >» برای بازگشایی ویزارد هوشمند

3. **صفحه کاتالوگ محصولات (`view-catalog` - عکس‌های ۲۴، ۲۵، ۲۶ و ۲۷):**
   - تب‌های فیلتر هر دسته:
     - محافظت: `کلاسیک`، `نازک`، `بدون لاتکس`، `اقتصادی`
     - روان‌کننده‌ها: `آب‌پایه`، `سیلیکون‌پایه`، `بدون عطر`، `ساشه‌ای`
     - پریود: `روزانه`، `معمولی`، `شب`، `پوست حساس`
     - کیت‌های آماده: `همه`، `محافظت`، `پریود`، `سفر`، `پوست و مراقبت`
   - گرید کارت‌های محصولات با عکس ۳ بعدی واقعی، قیمت به تومان، وضعیت موجودی و دکمه «انتخاب»

4. **صفحه جزییات محصول (`view-product-detail` - عکس ۲۳):**
   - تصویر بزرگ محصول در سمت چپ
   - عنوان، ویژگی‌های بسته‌بندی با بج‌های رنگی، قیمت، وضعیت موجودی
   - کنترلر تنظیم تعداد اقلام (`- ۱ +`)
   - دکمه‌های «افزودن به سبد 🛒» و «بازگشت»

5. **صفحه سبد خرید (`view-cart` - عکس ۸):**
   - لیست محصولات اضافه‌شده به سبد با قابلیت افزایش/کاهش تعداد و حذف
   - کارت پیشنهاد مکمل هوشمند (Cross-Sell) با دکمه «افزودن»
   - محاسبه جمع کل و دکمه‌های «ادامه برای پرداخت >» و «ادامه خرید»

6. **صفحه انتخاب روش پرداخت (`view-payment` - عکس ۱۲ و ۲۸):**
   - مبلغ قابل پرداخت به تومان
   - ۳ کارت انتخاب روش: `کارت بانکی (انتخاب‌شده)`، `پرداخت با QR`، `پرداخت بدون تماس`
   - دکمه «شروع پرداخت 🔒» و تذکر عدم ذخیره‌سازی داده‌های پرداخت

7. **صفحه در حال پردازش پرداخت کارتخوان (`view-pos-processing` - عکس ۲):**
   - حلقه پیشرفت دوار دور دستگاه کارتخوان POS
   - پیام‌های «کارت خود را خارج نکنید» و «لطفاً چند لحظه صبر کنید»
   - دکمه‌های شبیه‌سازی تایید یا خطای کارتخوان جهت تست

8. **صفحه خطای پرداخت (`view-pos-error` - عکس ۳):**
   - پیام «پرداخت انجام نشد - مبلغی از حساب شما کسر نشده است»
   - ۳ گزینه: «تلاش دوباره 🔄»، «تغییر روش پرداخت 💳»، «نیاز به کمک دارم 🎧»

9. **صفحه در حال تحویل کالا با چرخش موتور (`view-dispensing` - عکس ۴ و ۳۰):**
   - بج «پرداخت موفق بود ✓»
   - نمایش انیمیشن دور دریچه تحویل کالا و نمایش بلادرنگ مراحل باینری سخت‌افزار (Stage 1 تا 5)

10. **صفحه انیمیشن کرکره وندینگ (`view-shutter` - عکس ۷ و ۱۰):**
    - پیام «در حال باز شدن کرکره» با نوار درصد و پیام هشدار «یک قدم عقب بایستید»
    - کلید «توقف اضطراری ✋ (STOP 0x07)»

11. **صفحه تحویل کامل شد (`view-complete` - عکس ۱، ۶ و ۱۳):**
    - تیک بزرگ سبز رنگ و تصویر جعبه کالا داخل دریچه تحویل روشن
    - پیام «لطفاً کالای خود را از محل تحویل بردارید»
    - دکمه «دریافت کردم >» و «دریافت رسید با QR»
    - تایمر معکوس ۱۵ ثانیه‌ای برای ریست خودکار به صفحه اول

12. **ویزارد راهنمای انتخاب هوشمند ۲ مرحله‌ای (`view-decision-guide` - عکس‌های ۱۸، ۱۹، ۲۱ و ۲۲):**
    - سؤال ۱: نوع نیاز (کاندوم، پد، روان‌کننده، کیت فوری)
    - سؤال ۲: حساسیت به لاتکس (بله، خیر، مطمئن نیستم)
    - سؤال ۳: نوع ترجیحی (کلاسیک، نازک، سایز بزرگ، فرقی ندارد)
    - نتیجه هوشمند: پیشنهاد دقیق محصول متناسب با حساسیت و ویژگی‌ها با دکمه انتخاب مستقیم

13. **تحویل سفارش اپ موبایل (`view-app-pickup` - عکس ۱۴):**
    - شناسایی کد سفارش (۴۸۲۱)، اتصال امن و فاصله مناسب، و دستور تحویل کالا

14. **مرکز راهنما و پشتیبانی (`view-support` - عکس ۹):**
    - ۴ موضوع کمکی: مشکل پرداخت، کالا تحویل نشد، مشکل کرکره، دسترس‌پذیری

15. **مدال تنظیمات زبان و دسترس‌پذیری (عکس ۲۰):**
    - انتخاب زبان (فارسی، انگلیسی، عربی)
    - سوئیچ‌های متن بزرگ، کنتراست بالا و راهنمای صوتی

16. **پنل مخفی مدیریت اپراتور (Admin Modal):**
    - فعال‌سازی با ۵ بار کلیک روی نشانگر وضعیت بالای صفحه
    - تست زنده PING با محاسبه تاخیر، کنترل ۸ خروجی رله (`0x04 SET_OUTPUT`)، آزمون چرخش موتور هر اسلات (`0x06 DISPENSE`)، و مانیتور زنده کدهای هگز استریم باینری ATmega.

## ۲. نحوه اجرا

```bash
npm test     # تست صحت محاسبات CRC16 و پروتکل باینری
npm start    # اجرای سرور کیوسک روی پورت 8080
```

آدرس رابط کاربری در مرورگر:
```
http://localhost:8080
```

## پالت رنگی برند

همه‌ی رنگ‌ها در `frontend/css/style.css` (بلوک `:root`) به‌صورت متغیر `--brand-*` تعریف شده‌اند؛ برای تغییر تم کافی است همین بلوک را ویرایش کنید.

| نقش | نام | کد |
|---|---|---|
| اصلی | Royal Violet | `#593796` |
| گرادیان / ثانویه | Magenta | `#803697` |
| گرادیان / ثانویه | Berry | `#A23391` |
| هشدار / تأکید | Raspberry | `#B4317F` |
| خطا / لغو | Signal Red | `#CF2846` |
| پس‌زمینه کیوسک | Lavender | `#F2EFFB` |
| سطوح | Pure White | `#FFFFFF` |
| نشان‌ها / هاور | Soft Pink | `#F1C5D8` |
| خط‌ها / تأکید ملایم | Dusty Pink | `#D9A0C0` |
| متن و سطوح تیره | Dark Charcoal | `#45404A` |

نام متغیرهای قدیمی (`--mint-*`, `--navy-*`) برای سازگاری حفظ شده‌اند ولی اکنون به رنگ‌های بالا اشاره می‌کنند.
